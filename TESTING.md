# Проверка визуальной переработки

## Установка и запуск

- Чистая `npm install`: успешно, 371 пакет; создан `package-lock.json`.
- `npm run dev -- --hostname 127.0.0.1 --port 4173`: успешно на Webpack с `WATCHPACK_POLLING=1000`; HTML отвечает HTTP 200.
- В изолированной среде стандартное файловое наблюдение вызывало `EMFILE`. Polling устраняет ограничение без изменения production-сборки.
- `npm run lint`: успешно, без ошибок и предупреждений.
- `npm run build`: успешно; TypeScript проверен, статический `out/` создан.

## Вёрстка и поведение

Проверено во встроенном Chromium-браузере:

| Ширина | scrollWidth | Колонки дверей | Нижняя граница hero CTA от начала страницы |
| --- | --- | --- | --- |
| 375 | 375 | 2 | 711 px |
| 390 | 390 | 2 | 721 px |
| 430 | 430 | 2 | 733 px |
| 768 | 768 | 2 | 572 px |
| 1440 | 1440 | 3 | 716 px |

- Горизонтального скролла нет.
- В мобильных viewport высотой 844 px CTA видна в первом экране.
- Клик по двери переключает `aria-pressed` в true, Enter возвращает false.
- Внутренние якоря существуют, CTA переходит к `#participation`.
- Две кнопки оплаты явно отключены до заполнения URL, социальные ссылки помечены «скоро».
- На мобильном загружается отдельный `hero-rabbit-alice-small.webp`.
- Реальные фотографии дверей визуально просмотрены в контактном листе и на странице.
- Desktop и mobile скриншоты показаны в чате. Сохранение отдельными файлами через macOS Preview было недоступно из-за отсутствия разрешения на управление нативным интерфейсом.
- `prefers-reduced-motion` предусмотрен в Framer Motion и CSS; системная эмуляция режима отдельно не запускалась.
- На реальных iPhone / Android устройствах и в mobile Safari отдельное тестирование не проводилось; проверены responsive viewport в Chromium.

## До публичного запуска

Локальная сборка без домена сообщает предупреждение о `metadataBase`: это не ошибка сборки. В Cloudflare поддерживается `CF_PAGES_URL`; для собственного домена нужно задать `NEXT_PUBLIC_SITE_URL` и пересобрать сайт. Заполнить часовой пояс, срок записи и payment/social URL.

Атрибуция фотографий: `/image-credits.html`, ссылка в footer. Она должна оставаться доступной при публикации. Лицензии распространяются на соответствующие фотографии; весь сайт не объявляется произведением под CC BY-SA.
