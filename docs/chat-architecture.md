# Проводник: mock-чат и дальнейшее подключение AI

Сейчас все ответы локальные: «Ассистент скоро появится здесь.». Нет сетевых вызовов к AI, endpoint `/api/chat` не создан. UI явно помечен как демо. Статическая сборка Next.js продолжает работать.

## Границы модулей

- `components/chat/ChatWidget.tsx`: кнопка открытия и окно; не выбирает модель или провайдера.
- `ChatWindow.tsx`: native dialog, Escape, фокус, visualViewport для клавиатуры.
- `ChatMessageList.tsx`: история и индикатор ожидания; ответы выводятся React как текст, HTML не интерпретируется. Роль system не отображается.
- `ChatInput.tsx`: ввод, отправка, Enter / Shift+Enter, поддержка IME.
- `lib/chat/types.ts`: ChatMessage, состояния, интерфейсы транспорта и хранилища, будущий контракт API.
- `chatClient.ts`: `sendMessage(messages: ChatMessage[]): Promise<string>`. Единственная точка замены mock на серверный запрос.
- `useChat.ts`: отправка, ожидание, ошибка/повтор, защита от параллельных отправок, таймаут 30 секунд, черновик и история сохраняются при закрытии окна в текущем сеансе.
- `historyStore.ts`: адаптер localStorage с проверкой данных и версией ключа. Можно заменить реализацией ChatHistoryStore для server session, базы данных или anonymous conversation id без изменения компонентов.

История ограничена 100 сообщениями и 4000 символами на сообщение. При запрете localStorage чат продолжает работать в памяти и показывает уведомление. Системные инструкции не принимаются из локального хранилища. Очистить историю можно удалением данных сайта в браузере. Черновик не сохраняется между перезагрузками.

## Будущий POST /api/chat — только контракт

Request: `{ "messages": [{ "id": "...", "role": "user", "content": "...", "createdAt": 0 }] }`.
Response 200: `{ "reply": "Ответ ассистента" }`.
Ошибки: 400 для невалидного запроса, 429 с Retry-After при превышении лимита, 5xx при недоступности провайдера. Адаптер должен проверять response.ok и тип/размер reply, затем возвращать строку или бросать ошибку для UI.

Перед реализацией:

1. Добавить серверный runtime. Текущий `output: "export"` не исполняет POST Route Handlers. Для статического Cloudflare-сайта нужен same-origin Worker/Function, либо переход на Next.js server deployment. Не добавлять фиктивный route.ts в статический экспорт.
2. Валидировать размер истории, длину сообщений, допустимые роли и тело запроса. Не доверять роли system, id и контенту из браузера. Сервер сам формирует системную инструкцию.
3. Хранить ключи провайдера только в server environment / secrets manager, без NEXT_PUBLIC_. `.env*` исключён из Git. Не помещать ключи в компоненты, localStorage, ответы API или логи.
4. Реализовать серверный rate limiting по сессии/anonymous id и IP с общим хранилищем, лимиты токенов и затрат, request timeout. Клиентский лимит длины не заменяет серверную защиту.
5. Системную инструкцию и источники контекста хранить в серверных модулях: описание мистерии, актуальные даты/тарифы, FAQ, разрешённые материалы курса и страницы. Закрытые материалы доступны только после серверной проверки доступа; не включать их в клиентский bundle. Внешние тексты считать данными, не инструкциями.
6. При включении сервера обновить заметки о демо и конфиденциальности в UI, поскольку сообщения начнут передаваться за пределы браузера. UI-компоненты и типы сообщений переделывать не требуется.

## Адаптивность и доступность

Native modal dialog удерживает клавиатурный фокус; Escape и кнопка закрытия возвращают фокус на launcher. На телефоне при открытии фокус на кнопке закрытия, чтобы не вызывать клавиатуру без выбора посетителя. После касания поля высота окна отслеживает visualViewport и safe-area. Текст input 16 px предотвращает автоматический zoom в iOS.

Launcher фиксирован справа снизу, но на mobile поднимается над видимой CTA. Если платёжный iframe занимает всю доступную область, launcher временно скрывается, чтобы не перекрывать оплату. Переписка не пропадает. Анимация индикатора отключена при prefers-reduced-motion.

## Проверки

`npm run test:chat` проверяет отправку, состояния sending/typing/error, retry без дублирования, чтение/запись истории, отказ localStorage и безопасный вывод HTML-подобного текста. Это DOM/логические тесты; они не заменяют проверку реального layout, нативного focus trap и экранной клавиатуры на iOS/Android.
