## Галерея и замена материалов

В `data/doors.ts` для каждой двери предусмотрены `id`, `style`, `alt`, `image`, `question`. Сейчас `image` и `question` равны `null`. Изображения временно заменены лёгкими CSS-эскизами, вопросы — явной подписью «Место для авторского вопроса». Цитаты Кэрролла не сочинялись.

| Эскиз | Временная реакция |
| --- | --- |
| Астрономическая | Свет, движение стрелки и орбиты |
| Ботаническая | Движение листа и контура |
| Подводная | Подъём частиц |
| Шахматная | Изменение геометрии полотна |
| Театральная | Лёгкий поворот полотна и свет |
| Ледяная | Усиление холодного света |
| Алхимическая | Поворот центрального знака |
| Книжная | Лёгкий поворот полотна |
| Зеркальная | Изменение отражения |
| Крошечная | Свет вокруг маленького входа |
| Небесная | Приподнимание полотна |
| Невозможная | Изменение перспективы |

Наведение, фокус клавиатуры и нажатие показывают место для вопроса. Касание переключает выбранную дверь; одновременно выбрана одна дверь. Escape снимает выбор. Enter и Space работают как у обычной кнопки. В режиме reduced motion отключены анимации и переходы, пространственные преобразования заменены статическим светом. Реальная настройка reduced motion на устройстве в этой сессии не переключалась.

Авторские файлы следует добавить в `public/images/doors/` в WebP или AVIF с подходящими размерами, затем указать `image` и обновить `alt`. Текущий компонент поддерживает адаптивные размеры и отложенную загрузку изображений. Финальные индивидуальные анимации необходимо адаптировать после получения авторских материалов. Скрытую драматургию в конфигурацию не добавлять.

## GetCourse

Проверен существующий виджет: https://tarotroad.getcourse.ru/pl/lite/widget/widget?id=1665193.

На момент проверки 25 ноября 2026 года он показывает даты «20 декабря 2026, 16:00» и «24 декабря 2026, 18:00». Тарифы и цены в открытом виджете не отображаются, поэтому соответствие предложений новым суммам не подтверждено. Заказы не создавались, персональные данные не вводились, оплата не выполнялась.

В `data/siteConfig.ts` установлен `checkoutEnabled: false`. Компонент регистрации не монтирует форму, внешний скрипт и ссылку на старую оплату. В `public/getcourse-init.js` есть дополнительная проверка разрешённого контейнера. Кнопки тарифов ведут к выбору предварительной даты. Выбор остаётся в памяти страницы, не отправляет заявку и не бронирует место.

Перед включением необходимо сверить оба предложения, суммы, доступные даты, отсутствие записи в письмах и продуктах, состав расширенного формата и страницы подтверждения. Затем обновить расписание и сценарий оплаты проводника, выполнить сборку и отдельно согласовать публикацию.

## Проверки

- Production-сборка Next.js 16.3.8 и TypeScript проходят.
- 62 теста проходят: чат, сохранение контекста, ответы по новым условиям, отказ от записи, сохранение тайны, блокировка загрузчика оплаты, обработка ошибок и согласие на передачу вопроса Марии.
- Проверка статического экспорта проверяет отсутствие секретов сервера и запрещённых сюжетных сведений в HTML, JS, JSON, TXT и CSS.
- В браузере проверены ширины 375, 390, 430, 768 и 1440 px: горизонтального переполнения нет.
- Проверены включение двери касанием, Escape, выбор даты и ответы чата о тарифах и записи.
- Форма GetCourse не загружается в preview; в DOM нет её платёжного iframe и скрипта.
- Новая галерея не загружает тяжёлые изображения. Существующие адаптивные WebP сохранены.
- Реальные сообщения в Telegram не отправлялись. Автоматические тесты эскалации используют имитации; локальный статический сервер не исполняет Cloudflare Functions.

При локальной сборке Next.js предупреждает об отсутствии `metadataBase`. Перед публикацией нужно задать утверждённый `NEXT_PUBLIC_SITE_URL`; локальный адрес не следует использовать в production-метаданных.

## Как открыть preview

На Mac дважды нажмите `preview.command` в корне проекта. Откроется http://127.0.0.1:3000. В терминале сервер останавливается сочетанием Ctrl+C. Этот запуск обслуживает уже подготовленную папку `out`, ничего не публикует и не принимает внешние подключения.

После дальнейших правок:

```sh
npm ci
npm run typecheck
npm run test:chat
npm run build
./preview.command
```
