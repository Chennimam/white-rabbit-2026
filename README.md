# За Белым Кроликом. 12 дверей

Production-конфигурация лендинга мистерии Марии Ухановой. Официальный адрес: https://rabbit.logos-journey.com. Техническая приёмка GetCourse и публикация с активными формами утверждены владельцем 26 ноября 2026 года.

## Событие

- 20 декабря 2026, 16:00–20:00 МСК; 24 декабря, 17:00–21:00 МСК (UTC+3).
- Четыре часа онлайн в Zoom, одна дата на выбор, без записи.
- Путешественник — 5 000 ₽; Исследователь — 11 000 ₽.
- Индивидуальная встреча — 60 минут, январь–февраль 2027, в согласованное время.
- Исследователь — 12 мест суммарно на обе даты, ручной контроль в GetCourse. Клиентский счётчик остатка отсутствует.

## Оформление

Утверждённые изображения, вопросы и литературные тексты сохранены. Поле галереи 6 × 4, двери только на светлых клетках `var(--paper)`, фактура общая со страницей. Вопросы появляются в соседних графитовых клетках. На планшете поле 4 × 6, на телефоне 2 × 12. Тринадцатая дверь остаётся крупной и отдельной.

Индивидуальные эффекты работают при наведении, фокусе и касании. Активная дверь увеличивается на 6,5%; reduced motion отключает движение. Исходные PNG и административный макет GetCourse хранятся локально и не входят в публичный репозиторий или экспорт сайта.

## Регистрация и оплата

`data/siteConfig.ts`: `checkoutEnabled: true`. `data/getcourse.ts` содержит две проверенные формы: Путешественник 1690986, Исследователь 1690990. Выбор даты — переключатель предложений внутри GetCourse; отдельного поля даты нет. Старый виджет не используется.

По подтверждённой пользователем приёмке Claude проверены все четыре сочетания тарифа и даты, письма, доступы и юридические согласия; тестовые данные очищены. Заказы, оплата, письма и доступы создаются только GetCourse. Подробные реквизиты — [контракт интеграции](docs/getcourse-form-contract.md).

В подвале четыре актуальных юридических документа GetCourse, ссылки заданы в `data/legalLinks.ts`. Сайт не принимает согласия за пользователя.

## Хостинг и GitHub

Репозиторий: https://github.com/Chennimam/white-rabbit-2026. Существующий Cloudflare Pages проект — `white-rabbit-2026`, production-ветка — `main`, автоматические deployments включены. Технический hostname — `white-rabbit-2026.pages.dev`.

DNS обслуживается REG.RU: `CNAME rabbit → white-rabbit-2026.pages.dev`. Основные записи `@`, `www` и NS не меняются. Custom domain привязывается к существующему Pages-проекту, HTTPS выпускается Cloudflare. Фактические результаты запуска фиксируются в итоговом отчёте; один только конфигурационный файл не подтверждает завершённый deployment.

## Сборка и проверки

```sh
npm ci
npm run typecheck
npm run test:chat
npm run build
npm run check:functions
./preview.command
```

`out/` — статический экспорт; Cloudflare Pages также собирает `functions/`. 80 тестов проверяют чат, GetCourse, вопросы и неизменность изображений, управление галереей, SEO и служебные ограничения. Сборка проверяет клиентскую границу на серверные секреты.

SEO: официальный metadataBase/canonical, robots.txt, sitemap.xml, две записи JSON-LD с UTC+3, OG/Twitter 1200 × 630. Активные Offer используют проверенные формы и цены; остаток мест не выдумывается. Переменные подтверждения поисковых кабинетов: `GOOGLE_SITE_VERIFICATION`, `YANDEX_SITE_VERIFICATION`.

## Проводник

Сценарный помощник отвечает локально, без внешнего AI API. Источник фактов — `knowledge/white-rabbit-assistant-context.md`, ответы — `lib/chat/scenarios.ts`. Рабочий статус оплаты обновлён без изменения литературных текстов лендинга.

Передача вопроса Марии — отдельная Cloudflare Function `/api/escalate`, только после явного согласия посетителя. Сохраняются secrets `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, D1 binding `ESCALATION_RATE_DB`; `ALLOWED_ORIGINS` должен включать официальный origin. Секреты не входят в GitHub или frontend. [Описание](docs/telegram-escalation.md).

Датированные отчёты в `docs/` сохраняют историю этапов; их прежние ограничения публикации отменены явным разрешением владельца от 26 ноября 2026 года.
